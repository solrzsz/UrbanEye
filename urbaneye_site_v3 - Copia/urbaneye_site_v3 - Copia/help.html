Ajuda e segurança

Como usar o UrbanEye?

1
Explore o mapa
Veja problemas públicos por localização e categoria via API.
2
Reporte um problema
Informe categoria, local, descrição e, se possível, uma foto.
3
Acompanhe o status
Veja se o relato está aberto, em análise ou resolvido.
4
Confirme problemas
Confirmações ajudam a mostrar quais ocorrências afetam mais moradores.
Privacidade

Não publique telefone, documentos ou outras informações pessoais na descrição. Os dados são sincronizados através da API Mockada.
